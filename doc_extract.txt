7. Total Bill Wise Report (Billing INR OP)
Filter the Bill column: keep only rows where value = “O_B”.
Add column “Net” = TotalAmt − DiscAmt.
Add column “CAT” using the Section 3 mapping against the Category column.
Add column “Cash/Credit”: if Category = “General” → Cash. All other categories → Credit.
Add column “International/Domestic”: compare Category against Section 3 lists and tag accordingly.
Sum the Net column → Final output → “OP” row under Billing (INR).
Save updated file as: Total Bill Wise dd-mm-yyyy (today’s date).
8. Discharge Wise IP Revenue Report (Billing INR IP)
Filter the Bill column: keep only rows where value = “IP_D” or “IP_F”.
Add column “Net” = TotalAmt − DiscAmt.
Add column “Cash/Credit” (same rule as Section 7).
Add column “International/Domestic” (same rule as Section 7).
Remove the “Time” column.
Sum the Net column → Final output → “IP” row under Billing (INR).
Final output → “Total Billing” = OP (Section 7) + IP (this section).
Save updated file as: Discharge Wise dd-mm-yyyy (today’s date).

11. Bed Occupancy Report (emailed)

Paste to Final output:
Bed Strength = 1000 (fixed constant, always — not from source data).

Occupancy % = Beds Occupied ÷ 1000.

14. MTD & Daily Average (applies across Final output)
This is the shared formula used wherever the Final output sheet shows Month-to-Date and Daily Average figures alongside the daily value.
MTD (Month-to-Date) = sum of the value from the 1st of the current month up to and including the current day.
Daily Average = MTD ÷ day of the month (the current day’s calendar date number, e.g. 11 on the 11th).
(Which Final output rows carry MTD / Daily Average columns is not yet confirmed — to be mapped alongside the row numbers in Section 15.)
15. Final Output — Row Structure
The Final output sheet has a fixed structure. Main headings, sub-rows, and their order never change between days. Only the values are updated daily. Code should use hardcoded row numbers to write each value. There is no risk of row mismatch.
